## What this setting changes

This setting only changes **the language of the Calaos Home interface**, the one displayed on the touchscreen connected to the server.

{{% notice warning %}}
It does **not** change:

- the language of the mobile applications, which follow your phone's language;
- the language of the web app;
- the language of Calaos Installer, which is set in the software itself;
- the language of the system, that of the messages shown in a terminal;
- the names you gave your rooms and devices, which stay exactly as you typed them.

This is the most common misunderstanding: changing this setting will not translate your whole installation.
{{% /notice %}}

## From the touchscreen

Open the **Calaos Home** configuration screen and choose the language you want. The change is visible immediately.

This is the only place where this setting can be changed, and it only makes sense if a screen is connected to the server.

## If you have no touchscreen

This setting does not concern you: without a screen, Calaos Home is not used.

The language of your mobile applications follows your phone's, and that of Calaos Installer is set directly in the software.
