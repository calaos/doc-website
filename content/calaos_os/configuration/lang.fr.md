## Ce que ce réglage change

Ce réglage modifie **uniquement la langue de l'interface Calaos Home**, celle qui s'affiche sur l'écran tactile branché au serveur.

{{% notice warning %}}
Il ne change **pas** :

- la langue des applications mobiles, qui suivent celle de votre téléphone ;
- la langue de la web app ;
- la langue de Calaos Installer, qui se règle dans le logiciel lui-même ;
- la langue du système, celle des messages affichés dans un terminal ;
- les noms que vous avez donnés à vos pièces et à vos équipements, qui restent tels que vous les avez saisis.

C'est le contresens le plus fréquent : changer ce réglage ne traduira pas toute votre installation.
{{% /notice %}}

## Depuis l'écran tactile

Ouvrez l'écran de configuration de **Calaos Home** et choisissez la langue souhaitée. Le changement est visible immédiatement.

C'est le seul endroit où ce réglage se modifie, et il n'a de sens que si un écran est branché sur le serveur.

## Si vous n'avez pas d'écran tactile

Ce réglage ne vous concerne pas : sans écran, Calaos Home n'est pas utilisé.

La langue de vos applications mobiles suit celle de votre téléphone, et celle de Calaos Installer se règle directement dans le logiciel.
